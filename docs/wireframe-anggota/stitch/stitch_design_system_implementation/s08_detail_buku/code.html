Sinopsis

Selama 100.000 tahun terakhir, sedikitnya ada enam spesies manusia yang menghuni bumi. Kini hanya tersisa satu: Homo sapiens. Yuval Noah Harari menelusuri bagaimana kera tak berdaya mampu menjadi penguasa planet bumi melalui tiga revolusi besar: Revolusi Kognitif, Revolusi Pertanian, dan Revolusi Saintifik yang merevolusi daya imajinasi kolektif serta tatanan peradaban dunia hingga detik ini.
